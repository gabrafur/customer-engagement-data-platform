## Project description

Built an independent, locally reproducible customer engagement data platform using Python,
the PySpark DataFrame API, Spark SQL expressions, and Delta Lake patterns. The project turns
deterministic synthetic customer and transaction data into quality-checked, scored, ranked,
and idempotently stored recommendations.

The repository emphasizes failure-aware engineering: required data-quality gates,
deterministic ordering, bounded retries, explicit exhausted states, reconciliation,
side-effect-free as-of replay, a transactional-outbox model, DAG execution utilities, run
provenance, structured logs, and runtime counters. Automated CI validates strict typing,
linting, 52 tests including local Spark, 96%+ measured coverage, wheel packaging, and content
safety.

Local execution is the reproducible reference. A Databricks Asset Bundle and Delta MERGE
adapter are included as reviewable compatibility examples; no production workload or live
workspace is claimed.
